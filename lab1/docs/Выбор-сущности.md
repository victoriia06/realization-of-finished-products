# Выбор независимой сущности

Для выполнения лабораторных работ в качестве основной сущности выбрана сущность **Customer (Клиент)**.

Клиент является независимой сущностью предметной области «Реализация готовой продукции», поскольку может существовать в системе независимо от совершения конкретной сделки. Один клиент может участвовать в нескольких сделках, поэтому информация о нём хранится отдельно от информации о продажах.

Для сущности определены следующие атрибуты:

- `customer_id` — уникальный идентификатор клиента;
- `name` — ФИО физического лица или название организации;
- `address` — адрес клиента;
- `phone` — контактный телефон;
- `contact_person` — контактное лицо.

Сущность выбрана для дальнейшей реализации, поскольку содержит самостоятельные характеристики, требует проверки корректности вводимых данных и позволяет продемонстрировать инкапсуляцию, валидацию, перегруженные конструкторы, сравнение объектов и создание краткого представления.
